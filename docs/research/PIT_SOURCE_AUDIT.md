# CSI500 候选历史成分源审计

审计日期：2026-09-24  
结论：**不接入正式 FactorLab 数据链路；仅可作为人工核验线索。**

2026-10-09 补充：以下保留2026-09-24的候选档案审计。新的 [BaoStock 来源复核](BAOSTOCK_SOURCE_AUDIT.md)表明网络恢复也不足以证明逐日生效成员；该来源目前同样仅诊断，正式发布/消费均被语义门禁阻断。

- 候选仓库：`unliftedq/index-constitution`

候选文件按其自身 `opt-in <= date < opt-out` 规则，在 2021-09-13 至
2026-09-11 的每个自然日都能机械恢复 500 个成员；这只能证明内部计数一致，
不能证明 Point-in-Time 日期与证券代码正确。

## 阻止接入的问题

### 调样日期提前一个交易日

中证指数官方方法说明，常规定期调整在六月和十二月第二个星期五的下一交易日
生效。候选实现却把新成员的 `opt-in` 和旧成员的 `opt-out` 写成该星期五，并在
API 中把 `opt-out` 当作第一个不再属于指数的日期。因此，它会在星期五交易时段
提前完成调样。

研究区间内受影响的边界为：2021-12-10、2022-06-10、2022-12-09、
2023-06-09、2023-12-08、2024-06-14、2024-12-13、2025-06-13、
2025-12-12、2026-06-12。与“下一交易日生效”相比，共产生 998 个错误的
股票—日成员标记。

- 官方方法：[中证500指数编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000907_Index_Methodology_cn.pdf)
- 候选自身的 2026 调样证据：[PR #6](https://github.com/unliftedq/index-constitution/pull/6)

### 历史证券代码被当前代码覆盖

候选维护策略会把当前 ticker 反向用于全部历史。审计样例 `SZ302132` 被记为
自 2007-01-15 起属于历史序列，但该代码由 `300114` 在 2025-02-17 变更而来。
直接用该 symbol 关联 AKShare 历史行情会造成缺失或错误拼接。

### 历史密度与来源链不足

500 行被统一回填至 2007-01-15，其中包含当时尚不存在的板块/证券；文件在
2007 至 2026 年只有 23 个不同边界日期，早期调样历史明显不完整。初始 CSI500
历史提交没有逐行公告 URL、公告日期和内容哈希。仓库声明 MIT，但上游指数数据
的再分发授权链没有单独说明，因此也不把候选文件复制进本仓库。

## FactorLab 决策

1. 不建立自动 fallback，不绕过 `POINT-IN-TIME UNIVERSE REQUIRED`。
2. `import-universe` 明确拒绝原始 `opt-in/opt-out` 布局，不猜测公告日、基准日、
   排他退出日或时变 ticker 的含义。
3. 仅接受逐日有效快照，或已经转换为
   `entry_date <= trading_date <= exit_date` 的显式闭区间。
4. 若未来采用该候选作为线索，必须逐次对照官方公告，修正真实生效交易日，
   建立历史 ticker 映射，为每次转换保存来源 URL、公告日期和内容哈希，并再次
   验证每日恰好 500 个唯一成员。

## 已实现的安全替代入口

本次审计后，`import-universe` 已扩展为可接受人工核验后的显式闭区间，同时保持
fail-closed：

- 日级与区间日期只接受规范 date-only 值，拒绝时区、时分秒和数值时间戳；
- `entry_date`、`exit_date` 均必填且首尾包含，只在 benchmark 交易日历上展开；
- 拒绝重叠/倒置区间、混合布局、未知列及原始 `opt-in/opt-out` 语义；
- 每日覆盖和 500 个唯一成员仍是硬门槛；
- v2 manifest 同时绑定原文件、规范化 daily 和重新压缩 intervals 的 SHA-256；
- v1 本地导入仍兼容读取，但 intervals 也必须能由 daily 精确重建；
- writer 使用独占锁、所有权 token 和唯一临时文件，manifest 最后发布。

验收环境为隔离 Python 3.9；最终离线回归结果为：

```text
321 passed, 2 deselected, 13 warnings
```

其中两个 deselected 项为显式 network marker，不把离线结果表述成真实 PIT 数据已
取得。真实五年实验仍需 BaoStock 恢复，或导入逐次对照官方资料后的可靠历史成分。

这一结论不评价候选项目的一般用途；它只说明该文件不满足本研究对无幸存者偏差、
精确交易日和可审计来源的正式回测要求。
