## 公司行为和 HFQ 正式认证阻断

该局部价格一致性不能证明全五年单位、RAW 设置、身份、状态或 HFQ 资格。
旧单次浦发现金公告佐证 2025-07-16 的事件；公告落款、归档日期与当年精确可知时刻仍需区分。

仍缺六类独立证据：

1. 每证券适用期间的完整已实施事件、取消/更正/改期链，含现金、送转、配股、拆合股及特殊事件。
2. 明确的历史锚点、供应商绝对尺度和当时可知时间，不能把本地历史首行设为任意因子 1。
3. 经来源血缘核验的独立 HFQ 四价导出；同上游的 SDK、直连与代理表示不是多个独立来源。
4. 供应商完整算法、同日顺序、参考价、比例/货币单位及明确舍入规则。
5. 历史 vintage/修订记录；今天重建的历史只能标为 `HISTORICALLY_RECONSTRUCTED`。
6. 与行情相符的历史身份、上市/退市/换码、ST/交易状态与原价设置/单位证据。

## FactorLab 复用与失败语义

复用现有精确 18 列 Schema、`ParquetBarCache` v3、provenance、真实观察交易日历及探索采集器。
v3 先写不可变数据 generation，再原子切 metadata pointer；按证券记录成功请求覆盖区间，
缺少行情行的日期不能自动解释为停牌。已有 OS writer lock 和原始失败收据不删除。

普通网络失败进入独立 `RunManifest`/采集尝试记录；`download_status.py` 的 append-only
ledger 专门保留未解决数据合同失败。切换供应商、读旧缓存或重新运行不能消除致命合同失败。
取得完整真实非空覆盖并验证后才可能解除对应失败窗口，缺失价格保持缺失。
来源 SHA 与原子发布是可复现证据，不是外部金融真实性或当年可知时点认证。

预热与标签尾部分开：目标研究区间前 130 个基准观察交易日从 2021-03-08 开始。
这支持既有固定后向窗口，不证明每个晚上市/停牌证券有完整预热。
标签仍是 `t+1 adj_open → t+6 adj_open`；没有取得研究终点后 6 个真实交易日时，
末尾标签必须未成熟。已知缺口或迟上市造成的额外标签缺失单独报告。

## 性能和扩展依据的限度

本次只读取与哈希核验旧资产，没有进行新五年真实规模测量。
已有 500×1,200 日、130 预热日的合成软件诊断可作工程容量参考：
600,000 行旧 dataset 的 DataFrame deep bytes 为 335,856,128，约 320.30 MiB，
该值不是进程峰值。旧配对优化评价 ALL 中位数 13.253 秒，评价结束前生命周期
Peak Working Set 中位数 1,099.62 MiB；输入是人工数据且整机负载未隔离。
这些历史数字不构成本轮真实稀疏数据、完整模型或采集吞吐保证。

39 候选旧 private 运行只覆盖 17,950 行开发面板，配置的 `max_panel_rows=250000`。
500×1,211 日为 605,500 行研究面板，超出此冻结候选开发预算。
不能直接放大或放宽搜索预算并称本轮已验证；未来历史复核应设计按冻结表达式的分块计算、
缓存预算和横截面评价合并方案，再以等价性/内存证据验收，且不进行新搜索。

扩展最先受历史成员、退市取数、事件/状态资格及限频重试影响。
磁盘需保留原响应、转换结果、各不可变代和独立失败收据；暂存与峰值内存需实测，
不能按最终 Parquet 文件大小推算峰值。
下一阶段应并行补强正式 PIT/HFQ/身份状态资格与冻结样本覆盖，再分阶段扩大同源采集。
冻结因子的历史复核只在明确 `EXPLORATORY / UNVERIFIED / NON_PIT` 范围且缺失可审计时开展，
不能以探索可计算为理由解除正式准入。
