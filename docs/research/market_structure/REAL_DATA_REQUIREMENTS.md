# 未来真实来源需求矩阵

NO LIVE MONEY。此表为未来采购/接入的合同要求，本阶段未申请、下载、验证或接入任何真实来源；全部真实来源状态为 REAL_RESEARCH_BLOCKED。

|范围|必要字段与粒度|历史版本及可知证据|缺失和准入要求|
|---|---|---|---|
|稳定主体及证券范围|历史稳定主体 ID、证券映射、交易日/日内范围、完整性声明|代码变更、上市退市、主体合并各自版本及有效时段；当时可取得的证据|不按当前证券代码反推历史主体；母子公司关系不能隐式合并|
|行业板块|供应商体系、层级、分类版本、group_id、security_id、权重、变更日期|历史分类快照、成员调整、修订和撤销的发布时间/实际可用时间|禁止当前分类回填历史；每证券每体系权重守恒；未知范围不能解释为空归属|
|概念主题|主题定义及版本、成员多对多归属、历史权重、命名变更|历史新增/移除、改名、回溯修订与撤销档案|明确完整范围、主题生命周期及未映射证券；不能只提供最新全量表|

|资金分类|主动方向判定规则、单笔计额规则、buy/sell/unclassified、单位币种、阈值版本|供应商口径文档、规则切换和实际发布时间/可用时间|逐笔金额只分类一次；报告未分类金额占比；无定义主力资金不得准入|

|涨跌停状态|证券制度版本、窗口末状态、状态供应商及定义|当日制度和特殊处理的历史可知证明，日内状态更新时间|不能固定 10%/20% 推断；窗口内触及与收窗状态分开|
|日频基准与市场状态|显式交易日、实际日终时刻、同一价格基础、完整日频记录|日终真实发布时间/可用时间、迟到和复权修订档案|盘中禁止当日未来收盘；缺日保留，不压缩滚动窗口|
|使用权限|供应商、许可、可研究/可保留/可公开字段、脱敏边界|历史版本和归档权利、可重复验证路径|独立确认授权后才实施真实适配器；本 PR 不预先批准任何供应商|

所有来源还需提供来源定义版本、证据引用、可验证摘要、时区及时间精度。仅有日期的发布时间需未来适配器提出保守且可审计的时间上界，本首版不静默转换。真实数据输入接口、统计研究、模型训练和正式准入均需独立评审，不能用本合成验收替代。
